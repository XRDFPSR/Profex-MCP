Beamline Configuration

Parameter description

  • Sample-to-detector distance (D): The distance in mm between the sample and the detector surface along the primary beam.
  • Sample size (c):
    • For capillaries: The smaller value of the beam diameter and the inner capillary diameter in mm.
    • For transmission: The beam diameter in mm.

Setup

Enter all parameters according to the beamline setup. The graph will display the FWHM2 of the profiles as a function of cos2(2θ). The 2θ range can be adjusted on the "Computation Range" page.

Checkboxes are used for fitting the parameters to support peaks. See page "Support Peaks" for more information.
