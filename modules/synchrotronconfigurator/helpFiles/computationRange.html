Computation range

Determine the 2θ range in which the profile shape is calculated. Changing the start and end also affects the FWHM2 graph range.

Parameter description

  • Computation range start: Lowest 2θ angle for which the profile shape will be computed for. Should be 0 or close to 0.
  • Computation range end: Greatest 2θ angle for which the profile shape will be computed for. Should be slightly greater than the 2θ range covered by the area detector.
  • Computation interval: Interval in 2θ at which the profile shape will be computed. Recommendation: 0.2 degrees.
  • Pseudo-Voigt shape: Pseudo-Voigt shape parameter for the profiles. If unknown set to 0.5.
