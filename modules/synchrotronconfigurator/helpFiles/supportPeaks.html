Support peaks

If a reference dataset with ideal peak shape is available (no sample-related peak broadening), beamline configuration parameters can be fitted to these peaks as follows:

  1. Use conventional curve fitting to fit Pseudo-Voigt functions to the experimental peaks.
  2. Store the fitted parameters in a text file in the format:

    2theta;hwhm;shape
    2theta;hwhm;shape
    2theta;hwhm;shape

    2theta and hwhm must be given in degrees. Lines starting with "!" and "#" are treated as comments. Save the file with the extension CSV.
  3. Click "File -> Import support peak list" to load the peak list in the synchrotron configurator. The FWHMs of the support peaks will be drawn on the graph.
  4. Go to the "Computation range" page and adjust the 2θ range to the effective range covered by the current beamline configuration.
  5. Go to the "Beamline configuration" page and check the boxes of the parameters to be fitted.
  6. Click "Run -> Fit fundamental parameters."

Double-clicking support peak parameters allows to modify them after loading.
