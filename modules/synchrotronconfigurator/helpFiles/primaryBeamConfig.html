Primary Beam Configuration

Parameter description

  • Wavelength: The radiation wavelength in nm.
  • Beam divergence (φ): The beam divergence angle in degrees.
  • Focused: The beam is focused on the detector surface at 2θ = 0.

Setup

Enter all parameters according to the beamline setup.

Checkboxes are used for fitting the parameters to support peaks. See page "Support Peaks" for more information.
