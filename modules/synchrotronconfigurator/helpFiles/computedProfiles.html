Profiles

Displays the curve parameters of the computed profiles.

Computing profiles

Click "Run -> Generate Model Peaks" to compute the profiles from the fundamental parameters.

Fitting profiles

After computing the profiles, they must be fitted with L2 curves by clicking "Run -> Run Approximation".

Exporting the profile file

Save the fitted profiles to a GEQ file by clicking "File -> Save Instrument Profile file". Save the resulting files to one of Profex' device repositories.

The exported GEQ file will show up as a new instrument in Profex if saved to one of Profex' device repositories.
