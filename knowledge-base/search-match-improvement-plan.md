# Search-Match 优化计划 — 物相鉴定精度提升方案

## 当前瓶颈

| 问题 | 影响 | 优先级 |
|------|------|--------|
| 无强度信息 | 无法区分择优取向/区分同d值不同物相 | P0 |
| 无多相迭代扣除 | 低含量相被主相峰覆盖 | P0 |
| 指纹库依赖手工 | 维护成本高，容易遗漏 | P0 |
| 无置信度评分(FOM) | 无法区分多个候选 | P1 |
| 峰位精度不足 | 低角度峰误差大 | P1 |
| 非晶相检测缺失 | 3-2 非晶玻璃被忽略 | P2 |
| 择优取向校正 | 5-2/5-2b 结果不一致 | P2 |

## 优化方案

### 1. 强度加权匹配 + FOM 评分（P0，1天）
- 不需要精确强度，用"强/中/弱"分级代替（归一化 Three-tier）
- FOM = 匹配峰数 × 平均强度权重 / (1 + 未匹配实验峰数)
- 择优取向检测：如果最强峰与理论最强峰不符，标记"可能取向"

### 2. CIF → 理论衍射峰自动生成（P0，1-2天）
- 从 COD 下载 CIF → 用 Python 计算粉末衍射峰
- 不需要安装 pycodcif/pymatgen，直接用 BGMN 内核算
- 或者用 Python 的套公式法：Bragg定律 + 结构因子
- 生成所有常见矿物的 d 峰列表，自动化指纹库维护

### 3. 多相迭代扣除 Search-Match（P0，1天）
- Step 1: 全谱峰搜索
- Step 2: 匹配主相（匹配峰最多的）
- Step 3: 从实验峰中扣除主相的理论峰  
- Step 4: 在剩余峰中继续匹配下一相
- Step 5: 重复直到所有峰都有归属或无法匹配

### 4. 强度分级 + 择优取向提示（P1，0.5天）
- 对每个匹配的物相，将实验峰的强度排序与理论峰强度排序对比
- 计算 Spearman 秩相关系数
- 如果排名偏差大 → 标记为"择优取向可能"

### 5. 非晶相检测（P2，0.5天）
- 全局背景拟合（Chebyshev 多项式）
- 检测 >5° 宽的鼓包 (FWHM > 2° 2θ)
- 报告鼓包位置 + 半高宽作为非晶信息

### 6. 自动指纹库扩展（持续）
- 每遇到一个新物相（经人工验证），自动提取其 d 峰并加入数据库
- 验证数据集作为回归测试
