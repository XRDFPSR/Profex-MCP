Peak List

The peak list displays refined peak parameters read from the *.par file generated by BGMN and/or from peak detection runs.

Highlighting peaks in the graph

Selecting one or several peaks in the list will highlight the HKL tick marks in the graph (if "Show phase hkl tick marks" is activated in the preferences).

To clear the selection, click "Clear selection" from the cog wheel menu ("Tools"), or Ctrl+click on the last selected cell to unselect it.

Showing / hiding columns

Columns can be shown / hidden by right-clicking on the list header and checking or unchecking columns.

Filtering phases

Select either "All phases" or a specific phase from the "Phases" box to filter the peak list by phase name.

Phase names can also be filtered by entering a regular expression in the phase dropdown menu.

Example: The expression

.*[Aa]patite.*

will display the phases Chlorapatite, CO3ApatiteA, CO3ApatiteB, Fluorapatite, Oxyapatite, Hydroxyapatite, HydroxylapatiteM and HydroxylapatiteMonoclinic2.

Whereas the expression

Hydroxy?apatite

will only capture Hydroxylapatite and Hydroxyapatite.

Cog wheel button: Tools

Save peak data to file The currently displayed peak list is saved to a ASCII text file.

Remove selected peaks The selected peaks are deleted from the list. This change is volatile, no files are changed.

Reload data from file Reloads the peak data from the *.par file and updates the peak list. Previously removed peaks are restored.

Clear selection Clears the selection of peaks as well as the highlighting of peaks in the graph.

Filtering

Clicking the filter button opens a list of parameters, which can be limited to specific ranges.

Check the parameter you want to restrict, then enter the start and end of the range to be displayed by double-clicking the "Start range" and end "Range cells". Activating the checkbox activates the filter, deactivating it disables the filter.

Start and end of the ranges are automatically limited to the minimum and maximum value of the parameter found in the peak list.
