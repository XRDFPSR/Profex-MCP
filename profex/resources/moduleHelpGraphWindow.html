Interacting with graphs

Mouse actions

Left Mouse ButtonZoom
Ctrl + Left mouse buttonDrag view
Shift + Left mouse buttonSelect scan
Left double clickLoad reference structure with strongest peak at click position
Ctrl + Left double clickPrint current coordinates to refinement protocol console
Right mouse buttonReset zoom
Middle mouse buttonScale intensity of reference lines
Scroll wheelZoom horizontally
Ctrl + Scroll wheelZoom vertically

Keyboard actions

The graph must have keyboard focus.

Special cursors

C keyToggle cross hair cursor on / off
N keyToggle noise cursor on / off
S keyToggle spectral line cursor on / off
I keyToggle data inspection cursor on / off

Key sequences to navigate the graph

Type a key sequence followed by <Enter>.

Z <start> <end>Zoom angle to start and end values
<start> m=minimum, c=current, <numeric value>=value
<end> m=maximum, c=current, <numeric value>=value
ZI <start> <end>Zoom intensity to start and end values
<start> m=minimum, c=current, <numeric value>=value
<end> m=maximum, c=current, n=normalize, <numeric value>=value
Q <center> <width>Center the graph at <center> and zoom the view to <width>
W <width>Zoom the view to <width> at the current position.
Space barReset zoom

Panning and zooming

Arrow keysMove the scans
Shift + arrow keysMove the scans slowly
Alt + arrow keysMove the scans quickly
Ctrl + arrow keysStack the scans
Ctrl + space barReset stacking
Num +/-Zoom in / out horizontally
Shift + Num +/-Zoom in / out horizontally slowly
Alt + Num +/-Zoom in / out horizontally quickly
Ctrl + Num +/-Zoom in / out vertically
Shift + Ctrl + Num +/-Zoom in / out vertically slowly
Alt + Ctrl + Num +/-Zoom in / out vertically quickly
